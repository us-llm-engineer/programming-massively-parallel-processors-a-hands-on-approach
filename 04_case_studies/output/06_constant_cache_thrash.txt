==================== CONSTANT-CACHE BEHAVIOUR (NVIDIA GeForce GTX 1650 Ti) ====================
Kernels: 4096 blocks x 128 threads; identical arithmetic per atom (no cutoff test). 'ms' = minimum of 9 launches after priming.
Times below; cache hit rates for the same kernels are in output/06_ncu_summary.txt (Nsight Compute, see scripts/profile_kernels.sh).

---- E2. Distinct addresses within one warp (W = 512 iterations) ----

---- E3. Layout in constant memory: 1000 samples of (kx, ky, kz) ----
[book, Ch.8] separate arrays need several cache entries per iteration; a struct keeps a sample's fields together.
layout                         ms         vs 3 arrays
3 separate arrays (SoA)        2.013      1.00      
12-byte struct {x,y,z}         1.693      0.84      
16-byte struct (float4)        2.163      1.07      
  Read: a ratio below 1 means the struct layout is faster than three arrays on this GPU. The book's claim is about the
  G80 constant cache; this GPU's cache behaves differently, so the size of the difference here is what it is.
